# PhotoForm · 本地照片建模

在 Windows 本机浏览器上传照片，使用 **Hunyuan3D-2mini Turbo** 生成三维形状，再进行纯色分区和封闭实体分色，导出 STL / 3MF。

**0.2 更新：** 导入、设置/生成、检查/导出分成三个独立步骤；“任务与文件”支持查看全部历史、取消生成、查看文件占用及删除整项任务。可通过访问码在同一局域网使用本地模型。

本机运行 `启动应用.cmd`；其他设备访问时，在模型电脑运行 `启动局域网.cmd`，使用窗口显示的地址与访问码。服务电脑需要保持开机和服务运行；GitHub 仅保存源码，不提供模型推理服务。

> 当前是经过本机验证的应用与实验代码备份，不包含照片、模型权重或运行环境，也尚未达到高精度扫描的还原能力。

## 使用流程

已部署电脑双击 `启动应用.cmd`，访问 **http://127.0.0.1:8765**。

1. 上传单张照片，或用摄像头拍摄；可选择整个主体，或框选头部等区域独立生成。
2. 点击“下一步”进入独立设置页，设置打印尺寸、材料数量和表面提取密度，点击生成。默认三色、383 表面提取、关闭预览灯光。
3. 旋转检查形状，必要时调整材料色与照片投影视角。已有形状可直接重新分色或重提取。
4. 下载 3MF 或 STL 文件包。在切片软件中确认尺寸、耗材槽、薄壁、小孤岛及支撑后再打印。

也可导入彩色 PLY / 内嵌纹理 GLB / STL。多角度照片路线使用 COLMAP + OpenMVS，需要另装相应工具。

## 已验证与边界

- 本机使用 Miniconda、PyTorch 2.6.0+xpu 和 Intel Arc 核显，混元五步推理；不通过 Ollama，也不上传照片到云端。
- 42 项回归测试通过，前端编译与构建通过。最新 95 mm 独立头部的整体和三个分色 STL 下载后均封闭、法线一致、正容积，3MF/ZIP 可读取。
- 断点绑定照片和生成参数；已修复 Windows 状态文件短暂占用导致推理后失败的问题。完成的形状可复用，避免重复运行混元。
- 框选头部独立生成能集中模型容量；本次人物的眉眼、耳廓和头发结构更清楚。但眼镜附近仍有模糊/碎边，**没有自动头身融合，也没有训练出新的增强权重**。
- 更密的网格不等于更准确的五官。单图背面依赖推断；纯色分区也不等于头、手、衣服等语义识别。
- STL 本身不保存标准颜色。多个颜色实体保持共同坐标；导入切片器时应作为一个对象的多个材料部件。部件没有装配间隙或连接榫。
- 已有原猫模型的本机切片验证，但尚未完成实物打印和毫米级还原精度验收。

## 仓库内容

`app/`、`components/` 是界面；`backend/` 是本地推理、颜色、网格及导出流程；`scripts/` 是安装、诊断与历史实验脚本；`tests/` 是回归测试。

`data/`、`models/`、`tools/`、`node_modules/`、Conda 环境、日志和本机配置均忽略。实验文档中引用的照片、对比图和任务目录只保留在原电脑上；历史案例脚本可能依赖这些未分发的数据。

模型与第三方依赖的来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。本地模式只监听回环地址；局域网模式显式开启并使用访问码。不需要关闭杀毒、修改驱动或绕过系统安全策略。
